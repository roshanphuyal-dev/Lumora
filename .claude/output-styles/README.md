# Output Styles

No project-specific output style is defined yet — response tone/format is currently governed by the user's global Claude Code settings, not a project override.

Add a style here (as its own file) only if this project needs a *persona-level* override that differs from the user's global preference for every session in this repo specifically — e.g. a distinct voice for a docs-only pass vs. a code-implementation pass. Don't add one just to restate rules already covered by `CLAUDE.md`, `AGENTS.md`, or `.claude/rules/`.
