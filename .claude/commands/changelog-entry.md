Add a `CHANGELOG.md` entry for the change described in `$ARGUMENTS`:

1. Open `CHANGELOG.md`.
2. Under `## [Unreleased]`, add a line under the correct subsection (`### Added` / `### Changed` / `### Fixed`) — create the subsection if it doesn't already exist under `[Unreleased]`.
3. Phrase the entry as a user-facing statement (what changed for someone using the product), not an internal implementation note.
4. Remove any stray `_nothing yet_` placeholder line from the subsection you added to.
